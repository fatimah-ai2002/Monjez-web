# Monjez | مُنجِز 🚀
Smart Productivity & Time Tracking Dashboard.

## Description 📝
A professional web dashboard built with **HTML, CSS, and JavaScript** that allows users to track the actual time spent on each task using individual timers.

## Features ✨
- **Glassmorphism Design:** Modern and sleek UI.
- **Individual Task Timers:** Start and stop timers for each task separately.
- **Task Management:** Add, complete (check), and delete tasks.
- **Dynamic Greetings:** Changes based on the time of day.

## Technologies Used 🛠️
- HTML5
- CSS3 (Flexbox, Glassmorphism, Animations)
- JavaScript (DOM Manipulation, Intervals)
